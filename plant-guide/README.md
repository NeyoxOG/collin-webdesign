# Plant Guide – animierte Website

Statische, responsive Website auf Basis der bereitgestellten botanischen Designreferenzen.

## Enthalten
- responsive Desktop-/Tablet-/Mobile-Ansicht
- einzeln animierte botanische Elemente und Leaf-Sway-Effekte
- Scroll-Reveal-Animationen
- Parallax im Hero auf Desktop
- animierte Angebotskarten
- FAQ-Akkordeon
- Angebots-Modals
- mobile Navigation
- lokale Demo-Bewertungsfunktion ohne veröffentlichte Kundenbewertungen
- Kontakt über Telefon und E-Mail
- Impressum/Datenschutz als Vorlagen mit klar markierten Pflichtangaben
- Cloudflare-Pages-Header und `wrangler.toml`

## Cloudflare Pages
Der Ordner `plant-guide` ist direkt deploybar. Kein Build-Schritt notwendig. Bei manuellem Wrangler-Deploy im Ordner kann `npx wrangler pages deploy . --project-name plant-guide` verwendet werden.
